# Changelog

## 1.1.0 - 2026-04-14

- Fixed mandatory Google sign-in flow and persistent Firestore-backed sidebar chat bootstrap.
- Fixed floating-dot answer visibility for hovered question dots and improved floating answer card output.
- Fixed interaction rescanning so typed, selected, and clicked answers are re-detected reliably.
- Fixed URL hash mode to show the full answer hash in-page without requiring address-bar scrolling.
- Improved quiz prompting, added separate sidebar chat prompting, and added model/provider fallback behavior for Gemini, Groq, and OpenRouter.
- Expanded available llama-family model options and aligned popup model lists with shared constants.
